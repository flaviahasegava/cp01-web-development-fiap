## Exercícios

| 01 | Operadores de comparação (`!=`, `===`, `>=`) e a saída de cada um |
| 02 | Cálculo de IMC com `if/else` encadeado (abaixo do peso, peso ideal ou acima do peso) |
| 03 | Repetição de 1 até 10 com `for`, exibindo o valor da contagem |
| 04 | Listagem de um array de heróis (Marvel ou DC) |
| 05 | Verificação de permissão do usuário com operador ternário |
| 06 | Login com usuário e senha (`admin` / `1234`) |
| 07 | Média de 7 notas, com resultado de aprovado ou reprovado (média mínima 6) |
| 08 | Saudação com o nome digitado, usando template strings |
| 09 | Troca de senha, aceitando apenas se a nova for diferente da atual |
| 10 | Cálculo do valor final de um produto após desconto |

## Conceitos praticados

- Variáveis (`let` e `const`) e operadores
- Estruturas condicionais (`if/else` e ternário)
- Laços de repetição (`for`)
- Arrays
- Template strings
- Interação com o usuário (`prompt`, `alert`, `console.log`)
- Manipulação básica de eventos com `onclick`
